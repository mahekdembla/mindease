# Healing Space Images Folder

Place your custom images for the Healing / Hero card in this folder:

`frontend/public/healing/images/`

### Supported File Formats:
- `.png`
- `.jpg` / `.jpeg`
- `.webp`
- `.svg`

### How to Add Your Own Images:
1. Copy your image into this folder (`frontend/public/healing/images/my_image.jpg`).
2. Add the path `"/healing/images/my_image.jpg"` to `frontend/src/config/healingImages.js`.
