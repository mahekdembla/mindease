# MindEase Journal Ambient Audio Directory

Place your royalty-free ambient audio file here as `calm-ambient.mp3`:

File Path: `frontend/public/audio/calm-ambient.mp3`

The Journal page audio player will automatically stream `/audio/calm-ambient.mp3` with looping enabled and low initial volume (15-20%).
If no custom MP3 is present, the built-in MindEase Web Audio ambient synthesizer automatically generates a soft 432Hz ambient chord synth!
